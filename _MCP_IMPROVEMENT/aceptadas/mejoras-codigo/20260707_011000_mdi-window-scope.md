## Resumen

**Problema:** Tools con `window_title` parcial fallan cuando el contenido está en una
ventana hija embebida (formulario MDI dentro de la ventana principal del proceso).
`find_text` emite warning y escanea pantalla completa.

**Solución:** Al resolver ventana, si no hay match, buscar hijas del proceso target con
título parcial; usar rect de la hija para scope de OCR y list_elements.

## Cambio propuesto

- Función `resolve_window_scope(title, parent_pid)` con fallback a hijas
- `find_text` / `list_elements`: reintentar con hijas antes de full screen
- Respuesta incluye `resolved_window_title` para debug del agente
